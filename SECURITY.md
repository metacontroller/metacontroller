# Security Policy

## Supported Versions

We support only the latest release. We do not support older releases.

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting to report a vulnerability:

https://github.com/metacontroller/metacontroller/security/advisories/new

Do not open a public issue to report a vulnerability.

## Response

We are a small open-source project. We cannot promise a response time or a fix date.

## Contributing a Fix

We welcome fixes for vulnerabilities. Report the vulnerability privately before you open a public pull request.

## Disclosure Policy

The maintainers and the reporter decide together when to publish details. No one publishes details before the maintainers release a fix.

We name reporters only if they give permission.
